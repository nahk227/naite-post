# 나이테 우체국 — 세대 교차 고민 우체통

고민을 쓰면 **다른 세대의 누군가**가 답장을 보내는 웹 서비스. 시제품 v0.1.

## 바로 써 보기 (데모 모드)
`index.html`을 브라우저로 열면 됩니다. `config.js`가 비어 있으면 **데모 모드**로 동작합니다.
- 저장은 이 브라우저(localStorage)에만 됩니다.
- 답장 연습용 예시 편지 6통이 들어 있습니다.
- 내 고민에는 20초 뒤 '(데모 답장)'이 도착합니다.
- 처음부터 다시 하려면 개발자 도구에서 localStorage의 `naite_demo_v1` 키를 지우세요.

## 실서비스로 연결 (Supabase)
1. Supabase 프로젝트를 만듭니다.
2. **Authentication → Sign In / Providers → Allow anonymous sign-ins** 를 켭니다. 가입 없이 바로 쓰게 하는 핵심 설정입니다.
3. **SQL Editor**에 `supabase/schema.sql` 전체를 붙여 넣고 실행합니다.
4. `config.js`에 Project URL과 anon(publishable) 키를 넣습니다.
5. 정적 호스팅(Vercel, Netlify, Cloudflare Pages)에 폴더를 그대로 올립니다.

## 기능 (v0.1)
| 기능 | 내용 |
|---|---|
| 시작 | 나이대(필수)·성별(선택)만 입력. 이름·연락처는 묻지 않음 |
| 고민 보내기 | 주제 7종, 받는 세대 선택(인생 선배에게 / 젊은 세대에게 / 아무에게나), 음성 입력 |
| 답장 쓰기 | 다른 세대의 편지를 우선 배달하고, 오래 기다린 편지부터 배달. 48시간 안에 답장이 없으면 다른 사람에게 재배달 |
| 느린 우편 | 답장은 3~12시간 뒤 도착 (`schema.sql`의 `deliver_at`에서 조정) |
| 내 편지함 | 보낸 고민과 받은 답장, 내가 쓴 답장, 고마워요 우표 |
| 접근성 | 큰 버튼, '글씨 크게' 전환, 웹 링크만으로 이용 |

## 안전 장치
- **위기 신호 감지**: 자살·자해를 암시하는 표현이 있으면 109 안내 창을 띄우고, 편지는 `held` 상태로 운영자가 먼저 확인합니다.
- **연락처 자동 가림**: 전화번호, 이메일, 링크, 오픈채팅, SNS 아이디를 가립니다. 화면과 DB 트리거 양쪽에서 처리합니다.
- **도배 방지**: 하루 3통까지만 보낼 수 있습니다.
- **신고와 이용 제한**: `reports` 테이블과 `profiles.is_blocked` 컬럼으로 관리합니다.
- **권한(RLS)**: 내가 쓴 편지와 내가 받은 편지만 볼 수 있고, 답장은 도착 시각이 지나야 보입니다.
